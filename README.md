# Wellness Companion

Wellness Companion is a non-diagnostic consumer wellness product. The repository is currently in **Phase 2A.1: Synthetic Platform Foundation**. It contains a runnable platform shell and synthetic-only demonstrations; real health data, external integrations, authentication, AI, scoring, notifications, reports, payments, and product frontend features remain prohibited.

## Highest authority

The ratified [Governance Constitution](docs/governance/governance-constitution.md) is the highest governing document. The [Governance Registry](docs/governance/governance-registry.md) records the accountable authorities. No feature, architecture, implementation, AI system, operator, flag, or release may bypass them.

## Phase 1 review package

Start with the [documentation index](docs/README.md), then review the [Phase 1/1.1 package](docs/phase-1/README.md). The package covers product requirements, constitutional governance, architecture, provenance, quality, versioning, scoring, explainability, security, privacy, data, event sourcing, rollout controls, decisions, and roadmap.

Review the [Phase 2A.1 foundation package](docs/phase-2a/README.md) for architecture, setup, tests, and transition evidence. No product connection to WHOOP, Claude, Apple Health, Health Connect, or any external service is authorized. GitHub Actions now validates both documentation governance and the synthetic application foundation.
