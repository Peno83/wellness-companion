# Wellness Companion

Wellness Companion is a planned, non-diagnostic consumer wellness product. The repository is currently in **Phase 1.1: foundation hardening**. It contains documentation only: no production application code, integrations, databases, authentication, APIs, or frontend pages.

## Highest authority

The [Governance Constitution](docs/governance/governance-constitution.md) is the highest governing document. No feature, architecture, implementation, AI system, operator, flag, or release may bypass it.

## Phase 1 review package

Start with the [documentation index](docs/README.md), then review the [Phase 1/1.1 package](docs/phase-1/README.md). The package covers product requirements, constitutional governance, architecture, provenance, quality, versioning, scoring, explainability, security, privacy, data, event sourcing, rollout controls, decisions, and roadmap.

No connection to WHOOP, Claude, Apple Health, Health Connect, or any other external service is authorized in Phase 1.1.
