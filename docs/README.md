# Wellness Companion Documentation

**Current phase:** Phase 1.1, documentation and architecture only

## Authority order

1. [Governance Constitution](governance/governance-constitution.md) — highest authority; no feature or implementation may violate it.
2. Binding architecture and security standards — define how constitutional obligations must be met.
3. [Phase 1 product and technical documents](phase-1/README.md) — requirements, proposed methods, operational governance, decisions, and roadmap.

Subordinate documents cannot create exceptions to higher documents. A conflict blocks the affected work until human governance review resolves it.
